The problem

Illustrator wasn't built for Taigi

Illustrator's text engine was designed for English, Chinese and Japanese. Taigi in POJ or Han-Lo falls in between: Roman letters with tone marks, syllables joined by hyphens, and Hanji on the same line. Out of the box, Illustrator breaks lines at those hyphens and leaves “-” at the start or end of a line, can place tone marks such as a̍ beside their letter instead of on it, and spaces Hanji and Roman letters unevenly.

Much of this can be fixed by hand, but the settings are spread over several panels and dialogs (kinsoku, composers, No Break, justification, tracking), and few people know which ones matter or how they affect each other. Some can't be fixed with settings at all: the obvious fix, putting “-” in both lists of a kinsoku set, makes Illustrator push the hyphen down to the next line instead.

The script does it for you. One run applies tested settings to the whole document and keeps each hyphenated word on one line with No Break. Anything you untick is left exactly as it was.

What it does

Everything POJ and Han-Lo text needs, in one run

斷

Line breaking

No Break on every hyphenated word, Illustrator's Hard kinsoku rules for punctuation (built into the script, so they work in any language), and Illustrator's own hyphenation turned off so it can't add hyphens that look like Taigi ones.

a̍

Tone marks in place

Switches paragraphs to the Middle Eastern & South Asian Every-line Composer, which positions combining marks such as a̍, o͘ and ǹ correctly.

漢

Han–Lo spacing

A small gap wherever Hanji meet Roman letters, without typing spaces. The text itself stays correct Han-Lo spelling.

-

Tighter hyphens

CJK fonts often give “-” loose sidebearings, so ē-tàng reads like ē - tàng. The script pulls syllables back together.

≡

Justification and leading

Alignment, word and letter spacing limits, and auto leading, set across the document. The defaults match a typical justified book page.

✓

Check report

After running, it lists any line that still starts or ends with “-”, starts with ，。」, or looks loose, and saves the list to your Desktop.

The dialog

Your last choices are remembered. Defaults restores the original values, and anything unticked is left exactly as it is in your document.

How it works

Illustrator settings, and what the script works out itself

Some options set an ordinary Illustrator setting on all text, the same as you could do by hand in the Paragraph or Character panel. Others are worked out by the script character by character, which Illustrator can't do on its own.

Illustrator settings

The same value on all text. Untick an option and your own setting stays.

Worked out by the script

The script reads the text and decides, character by character, where to apply No Break or tracking.

  • 1
    Kinsoku: Hard rulesNo Break on punctuation and its neighbour, from a copy of Illustrator's Hard set. Works in any language and ignores the document's kinsoku sets.
  • 2
    Hyphenated wordsNo Break on each hyphenated Taigi word, in POJ and Han-Lo
  • 12
    Roman Orthography trackingTracking on Roman letters only; Hanji unchanged
  • 13
    Han–Lo spaceTracking only where Hanji meet Roman letters
  • 14
    Hyphen tighteningTracking around “-” and “--” inside Taigi words only
  • 15
    Check reportReads the finished lines and lists problems; changes nothing
Run it again after editing. The script's results are saved in the document as ordinary No Break and tracking settings, so they stay when you save and reopen. Text you type later isn't covered until you run the script again, which is always safe.

Install

Up and running in a minute

  1. Download the script

    Pe̍h-ōe-jī Layout Script.jsx: one file, nothing else to install. It works the same on macOS and Windows.

  2. Run it once, straight away

    In Illustrator, open your document and choose File › Scripts › Other Script…, then pick the file. The shortcut is ⌘ F12 on macOS and Ctrl F12 on Windows. To work on part of the document, select those text frames first; the dialog then offers Whole document or Selected text only.

  3. Or add it to the Scripts menu

    Copy the file into Illustrator's Scripts folder once, and it appears under File › Scripts every time. The folder belongs to the system, so copying asks for your password or administrator permission.

    macOS

    1. In Finder, open Applications › Adobe Illustrator 2026 › Presets › en_US › Scripts.
    2. Drag the downloaded file into the Scripts folder. Click Authenticate and enter your Mac password.
    3. Quit Illustrator and open it again.

    Or paste this into Terminal (it asks for your password):

    sudo cp ~/Downloads/*Layout\ Script.jsx "/Applications/Adobe Illustrator 2026/Presets.localized/en_US/Scripts/"

    Windows

    1. In File Explorer, open C:\Program Files\Adobe\Adobe Illustrator 2026\Presets\en_US\Scripts.
    2. Copy the downloaded file into that folder. When Windows asks for administrator permission, click Continue.
    3. Quit Illustrator and open it again.

    Or paste this into PowerShell opened with Run as administrator:

    Copy-Item "$env:USERPROFILE\Downloads\*Layout Script.jsx" "C:\Program Files\Adobe\Adobe Illustrator 2026\Presets\en_US\Scripts\"

    Change 2026 to your Illustrator version and en_US to your language folder, for example zh_TW for Traditional Chinese. If the script isn't in the menu after restarting, check that you copied it into the folder for the language Illustrator runs in.

You still need a font that supports POJ. The script fixes the layout, not the letters. Choose a font that has every POJ character, such as a̍, o͘ and ⁿ, or some words will show boxes or misplaced tone marks. Check a few words before laying out a whole book.
Before your first run: save a copy of the document. Undo can take several steps. Text that is locked or hidden, or sits on a locked or hidden layer or group, is skipped, so unlock it first.

Also for InDesign and Affinity

The same Taigi rules, with the same option numbers, for two more layout apps. Each is one file.

Affinity

Pe̍h-ōe-jī Layout Script (Affinity).js · tested with Affinity 3.3

  1. Open the Scripts panel.
  2. From the panel's menu choose Import Script… and pick the file.
  3. Run it from the Scripts panel.

Questions

Good to know

Which fonts can I use?

Any font that has every POJ character, including the combining marks in a̍ and o͘, and ⁿ. Many CJK fonts lack some of them, and Illustrator then shows a box or puts the mark in the wrong place. The script can't add missing characters, so choose the font first. This page uses GenKiMin2 TW and GenKiGothic2 TW, which cover POJ.

Can I run it on just part of the document?

Yes. Before running, select the text frames you want, a group that contains them, or click into a text with the Type tool. The dialog's Apply to choice is then set to Selected text only, and only those texts change, including the check report. Choose Whole document to run on everything. With nothing selected, the whole document is used.

Does it work while I type?

No. Illustrator scripts run when you start them. Run it again after adding text with hyphens, or at least once before you export. Running it again is always safe.

Why are some lines still listed in the check report?

“Starts with -” or “starts with ，” usually means a text block was locked or hidden, so the script skipped it. “Possibly loose” is an estimate: a justified line with much less text than the others around it. Fix it with a manual line break or a small edit.

Spacing looks odd after I edited some text

New text copies the No Break and spacing of the character before it. Option 2a, on by default, clears No Break before re-applying it. For spacing, tick 14a once to reset tracking, then re-apply any tracking you set by hand on titles.

Can I keep my document's own settings?

Yes. Untick an option and the script leaves that setting alone. Options 6 and 7 default to common book values; type your own numbers and they're remembered. Fields of unticked options are ignored.

Does it work if my Illustrator isn't in English?

Yes. The kinsoku rules are built into the script, a copy of Illustrator's Hard set, so they don't depend on set names in your language. Option 10 lists the mojikumi sets your Illustrator and document actually have, with the names your Paragraph panel shows.

I made my own kinsoku set with “-” in it. Do I need to change it?

No. The script keeps hyphenated words and punctuation together with No Break, which works whatever kinsoku set a paragraph uses. You can set the Paragraph panel back to Hard or None if you like; the script doesn't change it unless you tick option 9.

Why not use the non-breaking hyphen (U+2011) instead?

It works without a script, but your text would no longer contain the ordinary hyphen, which matters for searching, copying and other Roman Orthography tools. The script keeps the text as written and changes only the layout.
