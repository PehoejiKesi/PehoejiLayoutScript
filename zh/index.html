Adobe Illustrator 指令碼 · 台語白話字／漢羅 · v0.9.0 beta

Pe̍h-ōe-jī Layout Script

讓白話字與漢羅台語文斷行正確、間距平均。行首不再出現「-」，一鍵處理整份文件，每項設定都能調整。

0.9.0 版（beta）· 更新內容（英文）· 適用 Adobe Illustrator 2020 以後版本 · macOS 與 Windows · 只有一個 .jsx 檔案，免費 · 也支援 InDesign 和 Affinity

問題在哪裡

Illustrator 不是為台語設計的

Illustrator 的文字引擎是為英文、中文和日文設計的。白話字和漢羅台語文剛好介於中間：有聲調符號的羅馬字、用連字號連起來的音節，還有同一行裡的漢字。直接排版時，Illustrator 會在連字號處斷行，讓「-」出現在行首或行尾；a̍ 這類聲調符號可能跑到字母旁邊，而不是在字母上；漢字和羅馬字之間的間距也不平均。

這些問題大多可以手動調整，但設定分散在好幾個面板和對話框裡（避頭尾、書寫器、不換行、齊行、字距），很少人知道哪些設定有用、彼此又會怎麼影響。有些問題甚至無法只靠設定解決：最直覺的做法是把「-」同時加進避頭尾設定的兩個清單，結果 Illustrator 反而把連字號推到下一行行首。

這個指令碼幫你一次做好。執行一次，就把測試過的設定套用到整份文件，並用不換行讓每個含連字號的詞留在同一行。沒有勾選的項目，會完全保留原本的設定。

功能

白話字和漢羅需要的設定，一次完成

斷

斷行

每個含連字號的詞都套用不換行，標點符號套用 Illustrator Hard 避頭尾規則（內建在指令碼裡，任何語言版本都適用），並關閉 Illustrator 的自動連字，以免它加入和台語連字號一模一樣的「-」。

a̍

聲調符號位置正確

把段落切換成「中東和南亞每行書寫器」，讓 a̍、o͘、ǹ 這類組合聲調符號正確疊在字母上。

漢

漢羅間距

漢字和羅馬字相接的地方自動加一點間距，不必打空格，文字本身仍是正確的漢羅寫法。

-

收緊連字號

中日韓字型的「-」左右空間常常太大，ē-tàng 看起來像 ē - tàng。指令碼會把音節拉近。

≡

齊行與行距

對齊方式、字間距和字母間距的範圍，以及自動行距，全文件一起設定。預設值符合一般書籍內文的齊行排法。

✓

檢查報告

執行後列出仍以「-」開頭或結尾、以 ，。」 開頭，或看起來太鬆的行，並把清單存到桌面。

每個選項的前後對照

E. 檢查

15檢查報告

執行後，摘要會列出需要檢查的行，完整清單存到桌面（報告為英文）：

my-book.ai – Pe̍h-ōe-jī Layout Script 0.9.0
starts with "-"   Text 3, line 12: --來tō寫ē出--來，
ends with "-"     Text 4, line 7: Kóng ē chhut-
starts with ，    Text 5, line 4: ，聲調lia̍h準，tio̍h ē曉--ah。
possibly loose    Text 7, line 2: 漢字是寫中國話

「starts with "-"」通常表示該文字物件被鎖定或隱藏而被略過；「possibly loose」是齊行文字可能過鬆的估計。

運作方式

哪些是 Illustrator 設定，哪些由指令碼計算

有些選項是把一般的 Illustrator 設定套用到所有文字，和你在段落或字元面板手動設定一樣。其他選項則由指令碼逐字判斷，這是 Illustrator 本身做不到的。

由指令碼計算

指令碼讀取文字，逐字決定哪裡套用不換行或追蹤。

  • 1
    避頭尾：Hard 規則依照複製自 Illustrator Hard 設定的規則，對標點和相鄰的字套用不換行。任何語言版本都適用，也不受文件裡的避頭尾設定影響。
  • 2
    含連字號的詞白話字和漢羅裡每個含連字號的台語詞都套用不換行
  • 12
    羅馬字追蹤只對羅馬字母設定追蹤，漢字不變
  • 13

  • 14

  • 15

修改文字後請再執行一次。指令碼的結果以一般的不換行和追蹤設定存在文件裡，存檔後重新開啟也會保留。之後新輸入的文字要再執行一次指令碼才會套用，重複執行永遠是安全的。

安裝

一分鐘就能開始使用

  1. 下載指令碼

    Pe̍h-ōe-jī Layout Script.jsx：只有一個檔案，不必安裝其他東西。macOS 和 Windows 都用同一個檔案。

  2. 直接執行一次

    在 Illustrator 開啟文件，選擇檔案 › 指令碼 › 其他指令碼…，再選這個檔案。快速鍵在 macOS 是 ⌘ F12，在 Windows 是 Ctrl F12。只想處理部分內容時，先選取那些文字物件，對話框就會提供Whole document（整份文件）或Selected text only（只處理選取的文字）。

  3. 或加到指令碼選單

    把檔案複製到 Illustrator 的 Scripts 資料夾一次，以後就會一直出現在檔案 › 指令碼底下。這個資料夾屬於系統，複製時會要求輸入密碼或系統管理員權限。

    macOS

    1. 在 Finder 開啟應用程式 › Adobe Illustrator 2026 › Presets › zh_TW › Scripts。
    2. 把下載的檔案拖進 Scripts 資料夾，按鑑定並輸入 Mac 的密碼。
    3. 結束 Illustrator，再重新開啟。

    也可以把下面這行貼到「終端機」（會要求輸入密碼）：

    sudo cp ~/Downloads/*Layout\ Script.jsx "/Applications/Adobe Illustrator 2026/Presets.localized/zh_TW/Scripts/"

    Windows

    1. 在檔案總管開啟 C:\Program Files\Adobe\Adobe Illustrator 2026\Presets\zh_TW\Scripts。
    2. 把下載的檔案複製到這個資料夾。Windows 要求系統管理員權限時，按繼續。
    3. 結束 Illustrator，再重新開啟。

    也可以用以系統管理員身分執行開啟 PowerShell，貼上：

    Copy-Item "$env:USERPROFILE\Downloads\*Layout Script.jsx" "C:\Program Files\Adobe\Adobe Illustrator 2026\Presets\zh_TW\Scripts\"

    請把 2026 換成你的 Illustrator 版本，zh_TW 換成你的語言資料夾，例如英文版是 en_US。重新啟動後選單裡還是沒有，請確認檔案放在 Illustrator 目前使用語言的資料夾。

你仍然需要支援白話字的字型。指令碼處理的是排版，不是字形。請選擇包含所有白話字字元（例如 a̍、o͘、ⁿ）的字型，否則有些字會顯示成方框，或聲調符號位置錯誤。排整本書之前，先檢查幾個字。
第一次執行前：先把文件另存一份。復原可能需要好幾步。被鎖定或隱藏的文字，或位在被鎖定、隱藏的圖層或群組裡的文字，會被略過，請先解除鎖定。

常見問題

使用前須知

可以用哪些字型？

任何包含所有白話字字元的字型，包括 a̍、o͘ 裡的組合符號和 ⁿ。很多中日韓字型缺少其中一些字元，Illustrator 就會顯示方框，或把符號放錯位置。指令碼無法補上缺少的字元，所以請先選好字型。本頁使用的源樣明體 GenKiMin2 TW 和源樣黑體 GenKiGothic2 TW 都支援白話字。

可以只處理文件的一部分嗎？

可以。執行前先選取要處理的文字物件、包含它們的群組，或用文字工具點進某段文字。對話框的 Apply to 就會設為 Selected text only，只有這些文字會被更動，檢查報告也只檢查它們。選 Whole document 則處理整份文件。沒有選取任何東西時，會處理整份文件。

輸入文字時會自動套用嗎？

不會。Illustrator 的指令碼只在你執行時運作。加入含連字號的文字後請再執行一次，或至少在輸出前執行一次。重複執行永遠是安全的。

為什麼檢查報告還列出一些行？

「starts with "-"」或「starts with ，」通常表示某個文字物件被鎖定或隱藏，指令碼略過了它。「possibly loose」是估計值：齊行時某一行的文字比周圍的行少很多。可以手動換行或稍微修改文字。

修改文字後間距看起來怪怪的

新輸入的文字會沿用前一個字元的不換行和間距。預設開啟的 2a 會先清除不換行再重新套用。間距的部分，勾選一次 14a 把追蹤歸零，再重新設定標題等手動調整過的追蹤。

可以保留文件原本的設定嗎？

可以。取消勾選某個選項，指令碼就不會更動那項設定。選項 6 和 7 預設為常見的書籍數值，輸入你自己的數字後會被記住。沒有勾選的選項，欄位內容會被忽略。

Illustrator 不是英文版也能用嗎？

可以。避頭尾規則內建在指令碼裡（複製自 Illustrator 的 Hard 設定），不依賴各語言版本的設定名稱。選項 10 會列出你的 Illustrator 和文件實際擁有的標點符號擠壓設定，名稱和段落面板上顯示的一樣。

我自訂過含「-」的避頭尾設定，需要改掉嗎？

不需要。指令碼用不換行讓含連字號的詞和標點保持在一起，不論段落使用哪個避頭尾設定都有效。你也可以把段落面板改回 Hard 或「無」；除非勾選選項 9，指令碼不會更動它。

為什麼不用不斷行連字號（U+2011）？

不用指令碼也有效，但文字裡就不再是一般的連字號，會影響搜尋、複製和其他羅馬字工具。指令碼保留原本的文字，只改變排版。
